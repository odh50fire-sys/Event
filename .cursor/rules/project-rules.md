# Project Rules for CulturePop Event App

1. **Git Backup & Push**: Every modification must be committed and pushed to `https://github.com/odh50fire-sys/Event`.
2. **Korean Commit Message**: Commit messages must be written in concise Korean summarizing the changes.
3. **Plan MD Update**: Update `docs/culture_event_app_plan.md` on major modifications.
4. **Kids-related Exclusion**: Strictly exclude all kids/baby/children-related content across all categories.
