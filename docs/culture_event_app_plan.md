## 2. 프로젝트 관리 & Git 백업 규칙 (MANDATORY RULE)

1. **자동 Git 백업**: 모든 수정/추가 작업이 완료될 때마다 변경사항을 git에 커밋하고 GitHub 저장소(`main`)로 push한다.
2. **한글 커밋 메시지**: 커밋 메시지(comment)는 한글로 어떤 작업이 수행되었는지 간단명료하게 요약하여 작성한다.
3. **중요 변경 시 계획서(Plan MD) 갱신**: 기능 추가, 대상 시설 변경, 수집/필터링 룰 변경 등 중요한 변경사항 발생 시 즉시 본 계획서(`docs/culture_event_app_plan.md`) 및 아티팩트를 갱신한다.
4. **키즈 관련 항목 전면 배제 원칙**: 모든 행사 데이터(API/크롤러/로컬)에서 키즈/어린이/베이비/유아/육아 관련 항목은 `isKidRelated` 필터를 통해 원천 배제한다.

## 3. UI/UX 디자인 컨셉: 만화풍(Comic Pop) & 네오 브루탈리즘

최신 웹·앱 트렌드 중 하나인 **Neo-Brutalism(굵은 검은색 테두리, 하드 섀도우, 명확한 색상 대비)**과 **만화(Webtoon/Comic)적 시각 요소**를 결합하여 지루하지 않고 직관적인 인터페이스를 구현합니다.

### 주요 디자인 특징
1. **만화 컷 레이아웃(Comic Strip Grid)**: 캘린더 날짜와 상세 카드마다 웹툰 컷 테두리(2~3px 굵은 라인 + 하드 드롭 섀도우) 적용
2. **배지 & 말풍선 D-day**: `D-DAY`, `D-3`, `종료임박`, `무료관람`, `사전등록` 등의 뱃지를 만화 효과음/말풍선 스티커 스타일로 시각화
3. **카테고리 컬러 코딩**:
   - 🎨 **전시/미술**: 파스텔 옐로우 & 블랙
   - 🎪 **축제/행사**: 네온 오렌지 & 블랙
   - 🏛️ **컨벤션(EXCO)**: 민트 그린 & 블랙
   - 🎭 **공연/음악회**: 비비드 퍼플 & 블랙
   - 🛒 **쇼핑몰/마트 휴무**: 경고 레드 & 화이트
4. **인터랙티브 스탬프 투어**: 다녀온 행사에 도장을 찍으면 색종이 팡파레(confetti) 애니메이션 발동

## 4. 1차 타겟 시설 수집 및 쇼핑몰 휴무일 명세

### 1) 문화·전시 1차 우선 시설 (대구 중심, 키즈 제외)
- **EXCO (엑스코)**:
  - 수집 데이터: 와인&주류 페어, 커피박람회, 대구아트페어, 리빙디자인페어, 미래모빌리티 엑스포 등
  - 사전등록(얼리버드) 링크 및 마감 D-day 추적
- **대구미술관 (Daegu Art Museum)**:
  - 수집 데이터: 현재 진행 전시, 예정 전시(3개월), 도슨트 일정, 관람료, 정기 휴관일(매주 월요일)
  - 매월 마지막 수요일 '문화가 있는 날' 무료관람 안내
- **국립대구박물관 (Daegu National Museum)**:
  - 수집 데이터: 고대 복식/황금유물 특별전, 숲속 어쿠스틱 콘서트, 상설 전통직물관, 상시 무료 관람

### 2) 대구 주요 쇼핑 시설 휴무일 자동 계산 및 표시
- **코스트코 (대구점 / 대구혁신점)**:
  - 대구시 조례 적용: **매월 둘째, 넷째 주 월요일** 정기 의무휴무 자동 연산
  - 명절 휴무: 1월 1일, 설날 당일, 추석 당일 휴무
  - 캘린더 표기: 🛒 `[코스트코 휴무]` 만화 경고 뱃지 표시 및 D-day 계산
- **백화점 3사 (더현대 대구, 신세계백화점 대구점, 롯데백화점 대구점)**:
  - 정기 휴점일: 통상 **매월 1회 월요일 정기 휴점**
  - 문화생활과 쇼핑을 하루 코스로 묶어 방문할 때 헛걸음하지 않도록 알림

## 5. 기술 스택 (React + Vite + Tailwind CSS + Electron)

- **Frontend**: React 19 + TypeScript + Vite + Tailwind CSS v4 + Lucide Icons + Canvas-Confetti
- **Desktop Runtime**: Electron 45 (Window EXE 독립 실행 및 포터블 지원)
- **Packaging**: Electron-Builder (Portable `.exe` 및 NSIS 설치 파일 생성)
