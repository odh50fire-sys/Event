> **"대구·경북·부산·경남의 모든 전시·축제·공연을 내 바탕화면 8일 주간 캘린더로 한눈에!"**

## 1. 프로젝트 개요

| 항목 | 내용 |
| :--- | :--- |
| **프로젝트명** | **컬처팝 8Days (CulturePop) - 영남권 문화생활 & 쇼핑 캘린더** |
| **플랫폼** | Windows 10 / 11 데스크톱 애플리케이션 (.exe 단일 실행 파일) |
| **표시 주기 (8일 롤링)** | **오늘(Today)이 항상 맨 왼쪽(Day 0)에 고정 표시되며, 오른쪽으로 오늘+7일까지 총 8일간의 일정이 동시 표시**<br>- 날짜가 지나면 오늘이 자연스럽게 좌측 첫머리가 되고 새로운 +7일 일정이 맨 우측에 추가됨<br>- 과거(오늘 이전)로의 역주행은 비활성화되어 언제나 오늘부터 미래 8일간에 집중 |
| **스크롤 정책** | **화면 상하 스크롤 완전 제거 (100vh 고정 무스크롤 레이아웃)**<br>- 창 크기 안에 모든 8개 컬럼 및 컨트롤이 컴팩트하게 수납됨 |
| **일자별 표시 혁신** | **카테고리 칩 클릭 제어 + 최상단 지역축제 우선 배치 + 목록⇄상세 양방향 네비게이션 패널**<br>- 의도치 않은 마우스 조작 방해를 원천 차단하기 위해 **마우스 클릭 시에만** 대형 팝업 오픈<br>- 각 요일의 맨 상단에 미술관·박물관보다 먼저 **'지역 축제'**가 1순위로 표시<br>- 지역 축제가 많은 경우 '지역 축제'라는 단일 칩으로 묶여 깔끔하게 그룹화<br>- **목록⇄상세 양방향 넘나들기 지원**: 행사 카드 클릭 시 상세 페이지로 스무스하게 전환되며, 상단 `[← 목록으로]` 버튼으로 원래 목록 즉시 복귀<br>- **이전/다음 행사 슬라이드 탐색**: 상세 페이지에서 `[◀ 이전] 2/5 [다음 ▶]` 컨트롤을 통해 목록으로 나가지 않고도 같은 카테고리의 행사들을 연속으로 쾌적하게 탐색<br>- 행사 카드 내 행사명 바로 밑에 **진행 일정(시작일~종료일) 배지** 명확히 노출 |
| **지원 권역 (지역 필터)** | **영남권 전체(디폴트), 대구, 부산, 경북, 경남** 원클릭 선택 전환 |
| **수집 원칙** | **모든 카테고리에서 키즈/어린이/육아/유아/베이비 관련 항목 원천 배제 (성인·순수문화예술 중심)** |
| **쇼핑/생활 연계** | 대구/부산 주요 백화점(더현대, 신세계, 롯데) 및 대형마트/코스트코 정기 휴무일 자동 연산 |
| **디자인 톤앤매너** | **눈이 편안한 웜 아이보리/소프트 파스텔 & 감성 카테고리 컬러 코딩**<br>- 팝업 크기 화면 상하 최대화 및 폰트 1.5배 확대(15~18px) 적용<br>- 임박 D-DAY 박스 및 텍스트 1.5배 확대 적용으로 압도적 시인성 확보 |

## 2. 프로젝트 관리 & Git 백업 규칙 (MANDATORY RULE)

1. **자동 Git 백업**: 모든 수정/추가 작업이 완료될 때마다 변경사항을 git에 커밋하고 GitHub 저장소(`main`)로 push한다.
2. **한글 커밋 메시지**: 커밋 메시지(comment)는 한글로 어떤 작업이 수행되었는지 간단명료하게 요약하여 작성한다.
3. **중요 변경 시 계획서(Plan MD) 갱신**: 기능 추가, 대상 시설 변경, 수집/필터링 룰 변경 등 중요한 변경사항 발생 시 즉시 본 계획서(`docs/culture_event_app_plan.md`) 및 아티팩트를 갱신한다.
4. **키즈 관련 항목 전면 배제 원칙**: 모든 행사 데이터(API/크롤러/로컬)에서 키즈/어린이/베이비/유아/육아 관련 항목은 `isKidRelated` 필터를 통해 원천 배제한다.
