## 2. 프로젝트 관리 & Git 백업 규칙 (MANDATORY RULE)

1. **자동 Git 백업**: 모든 수정/추가 작업이 완료될 때마다 변경사항을 git에 커밋하고 GitHub 저장소(`main`)로 push한다.
2. **한글 커밋 메시지**: 커밋 메시지(comment)는 한글로 어떤 작업이 수행되었는지 간단명료하게 요약하여 작성한다.
3. **중요 변경 시 계획서(Plan MD) 갱신**: 기능 추가, 대상 시설 변경, 수집/필터링 룰 변경 등 중요한 변경사항 발생 시 즉시 본 계획서(`docs/culture_event_app_plan.md`) 및 아티팩트를 갱신한다.
4. **키즈 관련 항목 전면 배제 원칙**: 모든 행사 데이터(API/크롤러/로컬)에서 키즈/어린이/베이비/유아/육아 관련 항목은 `isKidRelated` 필터를 통해 원천 배제한다.

## 4. UI/UX 화면 구성 (상하 스크롤 0% 설계)

1. **상단 네비게이션 헤더 (`Navbar`, 52px)**
   - 로고 + [대구] [부산] [경북] [경남] 원클릭 탭
   - 시설별 필터 드롭다운, 무료 전용 토글, 실시간 새로고침
2. **임박 D-DAY 티커 (`DdayBanner`, 34px)**
   - 1줄 가로 스크롤 바로 임박한 마감/시작 행사 노출
3. **8일 주간 캘린더 그리드 (`WeekCalendarView`, flex-1 min-h-0)**
   - 가로 8열(Grid 8열) 균등 배치
   - 오늘, 날짜, 요일, 기관/카테고리별 칩 렌더링
   - 마우스 호버 시 카드 위치(좌/우)에 맞춘 스마트 플로팅 팝업
4. **이벤트 상세 팝업 (`EventDetailModal`)**
   - 팝업/칩 클릭 시 메인 화면에 띄우는 프리미엄 모달 오버레이
   - ESC 키 또는 배경 클릭으로 즉시 닫기 지원

## 5. 기술 스택
- **Frontend**: React 19 + TypeScript + Vite + Tailwind CSS v4 + Lucide Icons + date-fns
- **Desktop Runtime**: Electron 45 (Window EXE 독립 실행 및 포터블 지원)
- **Packaging**: Electron-Builder (Portable `.exe` 및 NSIS 설치 파일 생성)
